Import Songs

MIDI file (.mid)

Pick as many files as you like at once. Any standard MIDI file becomes a playable chart — instruments and pitch decide the lanes automatically. Then open the song and tap Pair audio to play the real recording (vocals and all) over the chart. Only import music you have the right to use.

Audio file (MP3 / M4A / WAV)

No MIDI needed — Cadence listens to the recording, detects the note attacks, and builds the chart itself. Vocals play as-is. Detection is automatic, so busy mixes chart less precisely than a paired MIDI. Analysis takes a few seconds.

Forge Sequencer project (.json)

Songs you compose in Forge Sequencer play here as first-party charts. The reader is tolerant of format details — if a file won't load, it will say so plainly rather than guess.

Why no direct online library?

Browsers block this page from downloading files from other sites (CORS). Download a MIDI with your browser, then import it here — two taps, works with any library.
